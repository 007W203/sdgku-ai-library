# Citation Machine

## Access

https://www.citationmachine.net/

## Description

Citation Machine is a web resource that assists with generating
in-text citations and reference-list citations.

Users can select a source type and enter bibliographic information
for formatting.

## Best Uses

Use Citation Machine for:

- Draft citation formatting
- Reference-list formatting assistance
- Checking citation structure

## Important Limitation

Automatically generated citations should be verified.

A citation generator can format incorrect metadata correctly,
which still produces an incorrect citation.

## AI Instructions

Never treat a generated citation as authoritative without checking:

- Author
- Title
- Date
- Publication
- DOI
- URL
- Volume
- Issue
- Pages

Prefer the original source metadata whenever available.
