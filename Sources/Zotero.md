# Zotero

## Access / Guide

https://guides.library.harvard.edu/zotero#s-lg-box-10155397

## Description

Zotero is a free, open-source citation and research-management tool.

It can help:

- collect source metadata
- organize research
- track sources
- insert citations into documents
- create bibliographies

## Best Uses

Use Zotero for:

- Managing research libraries
- Capturing source metadata
- Organizing PDFs
- Citation management
- Bibliography generation
- Long-term research organization

## AI Instructions

Metadata imported automatically should still be checked for accuracy.

Pay particular attention to:

- Author names
- Capitalization
- Publication date
- DOI
- Journal information
- Page numbers

Automated metadata is useful but should not be assumed flawless.
